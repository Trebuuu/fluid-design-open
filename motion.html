Motion

Everything springs.

Anything you touch moves on a spring you can catch mid-flight.
Anything you scroll past plays on a timeline you drive.

Catch one mid-flight

A spring is a duration and a bounce, the way SwiftUI writes it; stiffness and damping fall out of those two. Every named spring is generated into fg3-springs.css as a CSS linear() curve plus the duration it is normalised to. Pick one to play it on the glass chip.

Curves for choreography. Springs for touch.

A curve is fire-and-forget: it knows its duration before it starts and cannot be caught. That suits scroll reveals and entrances nobody touches. These are the eight most-used curves, measured from production stylesheets and played here over one second so the shapes compare.

  • --ease-standard

    cubic-bezier(0.4, 0, 0.6, 1)

    The most-used curve: nav, flyouts, curtains

  • --ease-in-out-quad

    cubic-bezier(0.45, 0, 0.55, 1)

    Staggered fade-in and gallery moves (easeInOutQuad)

  • --ease-out-cubic

    cubic-bezier(0.33, 1, 0.68, 1)

    Caption cross-fades (easeOutCubic)

  • --ease-in-out-cubic

    cubic-bezier(0.65, 0, 0.35, 1)

    The modal opening over .8 s

  • --ease-decel

    cubic-bezier(0, 0, 0.2, 1)

    Things arriving: the films modal

  • --ease-card

    cubic-bezier(0, 0, 0.5, 1)

    Card hover growth over .3 s

  • --ease-pop

    cubic-bezier(0.3, 2, 0.5, 1)

    Colour swatches popping in, 400 ms

  • --ease-exit

    cubic-bezier(0.11, 0, 0.5, 0)

    Plain exits (easeInQuad), 320 ms

Grab it. Throw it. It lands.

A drag follows the finger one-to-one from where it was grabbed. Past an end it stretches like rubber. On release the landing is chosen from where a flick would have carried it, then the nearest detent — the way a native scroll view decelerates.

The scroll system

Scroll is the timeline.

Choreography is described in markup: a JSON keyframe on an element, a start and an end written as scroll positions. Fluid Design Open reads that markup verbatim. Every linear range compiles to the browser’s own scroll timeline; whatever CSS cannot express runs in one JavaScript loop.

The markup format

data-anim-keyframe
a tween, class or event, as JSON (-0 to -10 for more)
data-anim-scroll-group
the scope anchors are looked up in
start end
scroll positions, written as expressions
anchors
other elements the expressions may measure
easeFunction
a named easing, bezier() or spring()
ease
lerp smoothing per frame (1 = none)
disabledWhen
classes on html that switch it off
cssClass event
toggle a class or fire an event at a position
properties
opacity x y scale rotation clip --any
<section data-anim-scroll-group="Cameras">
  <h2 data-anim-keyframe='{
    "start": "t - 100vh",
    "end": "t - 40vh",
    "opacity": [0, 1],
    "y": [60, 0],
    "easeFunction": "easeOutCubic"
  }'>Hands down.</h2>
</section>

One keyframe, two paths.

Both tiles carry the keyframe above. The left one compiles to animation-timeline: view() and never touches JavaScript while you scroll. The right one adds "ease": 0.1 — lerp smoothing, which only the JavaScript loop can do, so the whole element moves there.
