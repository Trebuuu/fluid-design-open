A chart never goes on glass.

Glass is chrome: it blurs and tints whatever passes behind it, so a line drawn on it changes colour every time the page scrolls. A chart sits on an opaque card. Put one inside a glass host and CHART refuses it in place, so the rule is visible exactly where it was broken.

    One attribute each.

    A chart is a host element with data-chart and its values. FG3.boot() draws every one it finds; call the primitive yourself when the data arrives later. The colour is the host’s color: the accent by default, a series or a semantic role when the series means something.

    SparklineBarsSeriesRingRingsDialStripColour classes

    Sparkline

    100 × 28 by default; it stretches to its host. No area unless you ask for one with data-area.

    <div class="metric">
  <span class="metric-name">Completed</span>
  <div data-chart="sparkline" data-values="0,0,0,0,0,0,58,186,332,490,641,804,964,1136,1222"></div>
  <span class="metric-value">1,222</span>
</div>

    Bars

    The baseline is zero unless you pass min — and the zero rule below says why you should not. highlight fills one bar solid.

    CHART.bars(host, [1864, 1850, 2012, 1977, 1941, 2105, 1222], { highlight: 6 });

    Series

    A sibling [data-chart-out] receives the readout; pointer, focus and arrow keys all drive one index.

    <div data-chart="series" id="pace" style="height: 180px"></div>
<p data-chart-out></p>
    CHART.series(document.getElementById('pace'),
  [140.1, 96, 74, 63, 58, 52, 49, 45.8, 42.7], {
    format: function (v, i) { return v + ' s per completed run at ' + (6 + i) + ':00'; },
    idle: 'goal 30 s · baseline 140.1 s'
  });

    Ring

    One value of one maximum. data-label replaces the generated title when you can say it better.

    <div data-chart="ring" data-value="1222" data-max="2160"
     data-label="1,222 completed of the 2,160 daily limit, 57 per cent"></div>

    Rings

    Outer to inner. color names a role; state is cooling (striped) or restricted (dimmed); a null value is drawn as missing. A sibling [data-chart-legend] is filled for you.

    <div data-chart="rings" data-center="61%" data-values='[
  {"label": "Build", "value": 244, "max": 400, "color": "series-1"},
  {"label": "Test", "value": 52, "max": 70, "color": "series-2", "state": "cooling"},
  {"label": "Deploy", "value": 39, "max": 70, "color": "series-3"}]'></div>
<ul data-chart-legend></ul>

    Dial

    Segments by kind: done, active, planned, empty, lost, warm, idle, error. Times are hours or "HH:MM".

    CHART.dial(host, [
  { from: 0, to: 6, kind: 'idle', label: 'asleep' },
  { from: '06:02', to: '06:05', kind: 'done', label: 'aurora Build' },
  { from: '06:18', to: '06:19', kind: 'empty', label: 'came back empty' },
  { from: 15.2, to: 15.25, kind: 'planned' }
], { now: '14:30' });

    Strip

    Height is asked; fill is people when a row has it, otherwise landed capped at asked — a Build batch completes more jobs than tasks. arrived: false draws the dashed outline.

    CHART.strip(host, [
  { at: '14:04:31', asked: 10, landed: 0, empty: true, label: 'basil Build' },
  { at: '14:06:02', asked: 8, landed: 14, people: 7, label: 'basil Build' },
  { at: '14:17:15', asked: 6, landed: 0, arrived: false, label: 'dune Build' }
]);

    Colour classes

    Marks draw in currentColor. Change it with a class, never a value: ch-series-1…ch-series-6 for data hues, ch-ok, ch-warn, ch-bad when the series is a verdict, ch-quiet for context.

    <div data-chart="sparkline" class="ch-series-2" data-values="…"></div>

    Readable without seeing it.

    Every chart is an image with a sentence for a title, written from its own data. The interactive ones take the keyboard. And a value that was never measured is drawn as missing, never as zero.

    Missing is missing

      dune’s Notify is paused, so its ring is drawn restricted: dimmed on a dashed rail. Review was never measured today: no arc, a dashed rail and a dash in the legend — not a zero.

      Reduced motion keeps the value

      • Rings and the dial land on their values at once; nothing springs.
      • Strip marks do not grow; empty outlines do not draw on.
      • The striped “cooling” ring stops drifting and stays striped.
      • A ring meter still moves when its value changes — slower, and without overshoot, because it reports something.

      Bars start at zero.

      A bar’s length is its value, so the axis starts where the value does. Cut it at 1,800 and a 14 per cent better Friday looks six times taller than Monday. The ratios below are measured from the drawn bars.

      Measuring…

      From zero: Friday is a little taller than Monday, because it was.

      Measuring…

      Cut at 1,800 the same numbers tell a different story. min exists for signed data, not for drama.

      Colour says which, never how much.

      Six series roles carry identity. On one screen a hue means one thing: a project, or a job kind — never both unless a legend says which is which. Amounts are length and angle; red is kept for stopping and for errors.
