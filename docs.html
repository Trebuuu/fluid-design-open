Chapter 01

Principles

Eight rules decide every dispute. Each one comes with the thing to do and the thing that breaks it, shown live where the difference moves.

1. Morph, don’t swap.

A thing that changes state changes shape. It never cross-fades into a different thing. A pill becomes a panel, a chip becomes a card, a drop becomes a bar. Here one sprung number, --progress, drives the whole silhouette.

Width, height, radius and the label all follow one spring. Press again mid-flight: it turns around without a jump.

One element, one spring. Press it.

A cross-fade shows two things at once, halfway through.

2. Glass is chrome, content is opaque.

Glass belongs to bars, capsules, controls over media and sheets at partial height. Never to a card, a table, a chart or a number, and never glass on glass. Inside .layer-content the material is removed structurally, so the rule cannot be forgotten.

Controls float over the media they control.

Landed today 1,222

A number on glass shifts with whatever scrolls under it.

3. A lens needs something to bend.

Glass sits over real imagery: the art painter, media, or content that scrolls beneath it. Over a flat fill it is only a bordered box, and it costs a refraction slot for nothing.

Over the art

The rim bends the colour behind it.

Over nothing

Over a flat ground the lens has nothing to show.

4. Colour is a role, never a value.

Nothing outside the token files names a colour. A role re-resolves on every [data-tone] element and under increased contrast; a hex does neither. One tinted primary per view.

.caption { color: var(--label-2); }
.chip-ok { background: var(--ok-fill);
           color: var(--ok-strong); }

Roles follow the tone, the band and the contrast setting.

.caption { color: #6e6e73; }
.chip-ok { background: rgba(0,130,47,.14);
           color: #007429; }

A hex is right in one tone and wrong in the other.

5. Motion is a spring, interruptible, and it reports state.

Everything interactive moves on a duration-and-bounce spring that keeps its velocity when you change your mind. Cubic curves are only for fire-and-forget scroll choreography. Reduced motion removes displacement, never information.

MOTION.spring re-aims and carries the velocity.

A CSS curve restarts from rest and kinks.

6. Scroll is the timeline.

Marketing surfaces are choreographed by scroll position in a declarative keyframe vocabulary, calmly: one idea per viewport. Content is authored in its final state, so no script, reduced motion and the base experience all show it finished.

<h2 data-anim-keyframe='{"start":"t - 85vh",
  "end":"t - 40vh","opacity":[0,1],"y":[30,0],
  "easeFunction":"easeInOutQuad"}'>Hello.</h2>

Position drives it; scrolling back reverses it.

setTimeout(() => {
  title.style.opacity = 1;   // plays once,
}, 1200);                    // whether seen or not

A timer plays to nobody and never reverses.

7. Density follows motion.

Glass gets denser, with more blur and more fill, while it moves or morphs, and relaxes at rest. The control bar goes from 7 to 14 px of blur and from 72% to 100% fill. MOTION.progress sets [data-m-moving] for exactly this.

.pose-item { background: var(--mat-platter-bg); }
.pose-item[data-m-moving] {
  background: var(--mat-platter-fill-fallback);
}

Denser in flight, so the label never smears.

.pose-item {
  background: var(--mat-platter-bg);
  transition: all .3s;   /* same density moving */
}

A thin material in motion turns to noise.

8. Measured, not asserted.

Every engine claim has a self-test assertion that was seen failing first. A test that never went red passes exactly the same when the product is broken.

const s = LG3.stats(bar);   // a 50 px bar
T('refraction: max >= 8 px, mean >= 2 px',
  s.max >= 8 && s.mean >= 2, s);

Break the optics once and watch it fail.

// refraction is strong enough now
buildMaps(cfg);

A comment is a claim, not evidence.

Chapter 02

Adopting

Plain files, one boot call, no build step. Link twelve stylesheets, load fourteen scripts, call FG3.boot(). Nothing reaches the network at runtime.

The files

Every module is a plain script that defines one global and never throws when a later module is absent. None of them mounts itself: FG3.boot() mounts them all, in order.

Boot

FG3.boot() is idempotent and never throws. It sets the tone, gives un-toned stage bands data-tone="dark", runs the capability gate, derives concentric radii, runs the corner fallback, then mounts ART3 LG3 SYM CHART MOTION ANIM DEVICE UI CHROME SHOW in that order. A module that throws is recorded in errors and the rest still mount. Finally it sets html[data-fg3="ready"] and dispatches fg3:ready.

// { version, ready, tone, capability, corners: { mode, count }, mounted: [...], errors: [] }

The page template

Every page copies _partials/page-template.html verbatim: the head order, the site navigation, the footer and the scripts. Change only four things: the <title>, aria-current="page" on your page’s link, the local navigation’s title and jump links, and <main>. Tone

A tone is an attribute, on <html> or on any element: every role re-resolves inside it. The reader’s choice wins, then an author’s data-tone on <html>, then a host’s html[data-theme], then the system setting. html[data-tone-lock] lets the author’s tone beat a stored choice. A stage band is dark before boot and with no script at all.

FG3.setTone('dark');   // stored as localStorage 'fg3-tone'
FG3.setTone('auto');   // back to author, host, then system
FG3.getTone();         // { tone: 'dark', mode: 'dark', source: 'user' }
document.addEventListener('fg3:tone', (e) => e.detail.tone);

…

Do not put data-tone on <html> unless the page must be pinned: an author tone beats the viewer’s appearance toggle. Put tokens on :root, never on <body>: the Artifact host owns the body and its attributes do not survive publishing.

Chapter 03

Colour

Neutral greys, Fluid’s violet as the one accent. Every colour is a role with a contrast contract, held against the hardest ground it lands on.

Grounds and inks

There are four kinds of ground, and each has its own ink. The page and its alternate band take --label and --label-2. A translucent fill takes the -on-fill inks, because #6e6e73 has no headroom there. A semantic tint takes its -strong ink. Art takes the on-art inks.

On-art inks

--on-art-1 and --on-art-2 are near-white, brand-tinted inks. They hold 4.5:1 only where the art under the copy is no lighter than OKLCH L .40 on a dark stage, or no darker than L .88 on paper. Every ART3 palette measures about L .6 under a headline, so fade the art away under copy with a mask, as this page’s hero does, instead of trusting the ink.

Semantic, system and series

Each semantic colour comes as four roles: the base ink, -strong for text on its own tint, -ink for text on the solid, and -fill for the tint itself. Pair them; never mix a tint with another role’s ink.

Increased contrast

The generated files carry a prefers-contrast: more block and a [data-contrast="more"] twin you can set yourself. It is a step toward the ink, not a raised target: refitting everything to 7:1 once collapsed --label-2 and --label-3 into the same hex. Materials thicken to their no-backdrop opacity, keylines go to 1.5 px and the focus ring to 3 px.

// on demand, for a page or a single band
document.documentElement.setAttribute('data-contrast', 'more');
band.setAttribute('data-contrast', 'more');

Chapter 06

Geometry

Three kinds of corner, and no others: fixed continuous corners, true capsules, and concentric corners derived from the container.

The continuous corner

The continuous corner is not a circle and not a plain superellipse. Its published path is a circular arc of about 0.9958r, eased into each edge by a cubic, so the bend starts 1.52866r from the corner and cuts 0.2915r in along the diagonal. CSS can draw corner-shape: superellipse(k), so Fluid Design Open fits the two numbers that decide how a corner reads, its onset and its 45° mass:

R = 1.52866 r                            onset matches the reference
1 - 2^(-1/n) = 0.291507 / 1.52866        45-degree inset matches the reference
n = 3.2761,  k = log2(n) = 1.7120        tokens round to k 1.71, scale 1.53

Measured against the reference path, the fit stays within 0.0114r everywhere: 0.50 px at r = 44, and 0.33 px at r = 28 with the rounded tokens. Position alone barely separates it from a plain circle of the same radius, which stays within 0.0125r; the two carry the same mass on the diagonal. What separates them is curvature. A circle’s curvature jumps from zero to 1/r where the arc meets the edge, 0.53r closer to the corner than the reference bend begins; a superellipse eases in the same way, and that is the softer shoulder you see. A plain superellipse(2) at the nominal radius misses by 0.19r, about half the mass.

Why border-radius reads 42.84 px

A token is the nominal radius times the scale: --r-lg is calc(28px * var(--r-scale)), which computes to 42.84 px. That is intentional. The corner’s visual mass matches a 28 px circular corner, but anyone comparing the raw computed border-radius will see a different number. Reverting is two numbers in fg3-tokens.css (--k-continuous: 2; --r-scale: 1 gives a plain superellipse).

Capsules

A capsule is border-radius: 999px with corner-shape: round: true semicircle ends. Scaling a capsule by 1.53 and squircling it reads as a lozenge. Short controls therefore use .capsule, never a continuous token. A scaled radius clamps when the box is too short (--r-lg needs a short side of at least 86 px, --r-sm at least 37 px); where it would, FG3 snaps the element to a true capsule and marks it [data-fg3-capsule].

Concentric corners

An inner corner is derived, not chosen: inner = outer − the measured gap, with a floor of 6 px. The gap is measured because a border, a gutter or a transform all change it. The fallback

corner-shape shipped in Chromium 139; elsewhere the declaration is dropped and a circle is drawn, silently. Where it is missing, FG3.boot() walks every stylesheet for every selector that declares corner-shape and redraws each element it matches. A box with no painted edge is held at border-radius: 0 and clipped to the exact superellipse. A box with a shadow, hairline or border is not clipped, because a clip would cut them; its radius becomes the circle of equal 45° mass, a circular corner. Glass hosts are skipped: a clip would kill their shadow. Silhouettes measured within 0.06 px of exact in both modes.

Force the fallback in Chromium with ?no-fd-corner-shape. It injects style#fg3-corner-emulation so the page truly renders as Safari would, and FG3.cornerState() reports what was shaped and how.

Blending

Highlights add light. Reduced motion

  • There is no blanket *{animation-duration: 1ms !important}. A blanket rule like that kills every state indicator and makes every style change on every element animate for 80 ms.
  • Displacement goes: enter and exit become a fade of 200 ms or less, parallax, scrub and art drift stop, --progress jumps to its end.
  • State survives: spinners, pulses and the working sheen keep moving, slower.
  • Scroll choreography is off (no-fd-enhanced) and every reveal shows its final state in place.
  • MOTION.progress, DEVICE.fold and every spring jump to the end value, and their callbacks still fire.
  • Autoplay starts paused; the progress fill keeps reporting.

    • Escape closes the topmost open surface, one level per press. ⌘K or Ctrl K opens the command palette.
    • Menus type ahead, and closing a menu or a navigation panel returns focus to the control that opened it.
    • Touch targets are 44 px even when the control draws smaller.

    Contrast

    • Text holds 4.5:1 against the ground it actually renders on, including text over art and glass, which the audit rasterises rather than skips.
    • 3:1 is allowed only for large text, 19 px semibold or 24 px regular and up, and for glyphs. --label-3 and --label-4 are 3:1 roles: never use them for captions or anything at 17 px or below.
    • Text on a fill uses the -on-fill inks; text on a tint uses its -strong ink; text on a solid semantic uses its -ink.
    • On-art inks hold only over art at or below OKLCH L .40; fade the art under copy instead.
    • The accent must stay at 3:1 or more on --bg-1 and --bg-2 in both tones, because it is the focus ring.

    Chapter 15

    Traps

    Every one of these fails without throwing. Each is written as what you see, why it happens, and the fix, consolidated from the builders’ notes and the glass material’s own list.

    Glass and backdrop16

    The glass goes flat during an entrance.

    Cause An ancestor with opacity below 1, a filter or a mix-blend-mode is a backdrop root; the lens samples nothing for the whole fade. transform, isolation, will-change: transform and contain: paint are safe.

    Fix Animate transform only, or use LG3.materialize. Never fade a glass ancestor.

    The blur “sometimes works”: a band of it filters.

    Cause A backdrop-filter on a child of a backdrop root only sees what was painted inside that root.

    Fix Put the filter on the host itself.

    A tint eats its own label when the glass turns light.

    Cause A positioned tint layer at z-index 0 or above paints over in-flow text.

    Fix Tint layers sit at z-index: -1, as lg3.css does.

    The lens vanishes and only a bright rim survives.

    Cause The bevel profile is singular at the silhouette; one pixel sets the normalisation maximum.

    Fix Clamp the tilt near 72° (data-lg3-max-tilt).

    The rim smears while the glass resizes.

    Cause Displacement maps are baked bitmaps pinned to the old box.

    Fix Nine-slice maps resize by attribute writes. A skip-rebuild guard must compare the border box, never ResizeObserver’s contentRect.

    A rectangular seam appears on scaled glass.

    Cause Maps were sized from getBoundingClientRect(), but the filter region is untransformed local space.

    Fix Size from offsetWidth and offsetHeight; divide merged shapes back by the scale.

    The glass reads as a bordered grey box.

    Cause There is nothing behind it to bend.

    Fix Put glass over art, media or scrolling content, or use chrome.

    Stacked glass turns muddy.

    Cause Glass cannot sample other glass.

    Fix Anything on glass gets a fill; never mix regular and clear in one view.

    The nav keeps white ink over a white band.

    Cause The sampler read art it did not overlap and clamped probes that fell outside it.

    Fix The engine samples only canvas[data-lg3-source] the host really overlaps; large hosts take a declared tone.

    A floating panel over art turns dark on a light page.

    Cause A large host takes its tone from whatever is behind its centre.

    Fix Pin data-lg3-tone to the band that opened it (chrome does this with [data-chrome-pinned]).

    Small text on glass over mid-tone art measures 3.0–4.2:1.

    Cause The engine has no legibility dim for mid-tone backdrops.

    Fix Components add a share of the --lg3-rt-* fill to their tint; for your own glass, light glass with dark ink measured 5.80:1.

    Labels on glass are the wrong colour.

    Cause They were styled from the band’s tone.

    Fix Style them from [data-lg3-appearance].

    Glass added after boot has no material.

    Cause LG3 does not observe new [data-lg3] hosts.

    Fix Call LG3.apply(host) or LG3.mount(root).

    A morph turned an ordinary panel into glass.

    Cause LG3.morph(x, el) applies the material to its destination.

    Fix Morph only between glass hosts that share a data-lg3-id.

    A merged control lost its shadow and hairline.

    Cause A smooth union is drawn through a mask; a shadow would outline the unmasked rectangle.

    Fix Expected. Rebuild after a move settles, not every frame.

    Glass on a clipped surface lost its shadow.

    Cause A clip-path cuts the shadow, and a drop-shadow filter would make the host a backdrop root.

    Fix FG3’s corner fallback skips glass; strengthen the edge instead.

    Timing and observers9

    A layout that works in a tab never runs in the background.

    Cause requestAnimationFrame does not fire in a hidden page, and headless Edge on Windows hides the page about 12 s in.

    Fix Pair every rAF with a timeout; never build a stopwatch on rAF. For tools, keep the page in front.

    A reveal never happens on a page opened in the background.

    Cause The first observer callback is not guaranteed on a hidden page.

    Fix FG3.whenSeen(el, fn, 1600): a deadline that fires only if the observer never reported.

    The sampler reads a blank 300×150 canvas.

    Cause First paint waited on an asynchronous observer.

    Fix ART3 paints synchronously when the canvas has a box.

    Art in a panel is a smear when the panel opens.

    Cause A canvas in a hidden panel paints at 0×0.

    Fix Observe for a real box, then paint.

    An indicator slides in from the edge on load.

    Cause Its transition was armed before its first placement.

    Fix Arm the transition one frame after placing it.

    A deep link animates instead of jumping.

    Cause behavior: 'auto' means “use CSS scroll-behavior”.

    Fix Use 'instant' with timed retries. The system sets no smooth scrolling.

    A swap hangs, or an animation will not restart.

    Cause animationend does not fire in hidden pages, and re-adding a class does not restart an animation.

    Fix A deadline of 900 ms; force a reflow between removing and adding.

    An intro never starts.

    Cause A pre-intro transform moved the element out of its own IntersectionObserver’s view.

    Fix Apply the offset only while the intro runs.

    A bar flickers between two states at one scroll position.

    Cause A threshold without hysteresis; each flip costs a map rebuild.

    Fix Two thresholds: the tab bar minimises at 32 px down and restores at 16 px up.

    Springs and choreography10

    Under reduced motion, spinners stop and every style change lags 80 ms.

    Cause A blanket *{animation-duration:1ms!important; transition-duration:80ms!important}: the transition property defaults to all.

    Fix Reduced-motion twins per tier, and a test that reads computed durations with the setting forced on.

    An easing silently does nothing.

    Cause A critically damped spring (ζ = 1) produced NaN inside linear(), which drops the declaration.

    Fix The critical branch has its own formula in spring.js.

    A transform ends 1 px short.

    Cause The last linear() sample was not exactly 1.

    Fix Force the final stop to 1.

    A spring plays too fast or too slow.

    Cause linear() is normalised to the transition’s duration.

    Fix Always pair --sp-x with --sp-x-ms.

    A spring can be up to 41% off mid-flight.

    Cause A linear() emitter that time-warps the curve.

    Fix Use toLinear from spring.js, and regenerate springs with tools/gen-springs.mjs.

    An interrupted animation kinks.

    Cause A CSS transition restarts from the current value at zero velocity.

    Fix MOTION.progress, MOTION.spring and MOTION.glide carry velocity.

    Two animations fight and one wins.

    Cause data-reveal and data-parallax both write translate; two springs on one transform jitter.

    Fix Separate elements; one spring per element per property.

    A keyframe runs in JS when it could be on the compositor.

    Cause A css() value, differing gates, or one property split across keyframes pushes the element to the JS path.

    Fix Keep keyframes numeric and scale in CSS; check ANIM.inspect(el).

    A curve with a negative handle plays wrong.

    Cause The bezier() parser drops minus signs, and ANIM reproduces it exactly.

    Fix Write signed curves as cubic-bezier().

    A morph stutters at 30 ms a frame.

    Cause Interpolating corner-shape’s k rebakes the unit field every frame.

    Fix Animate the radius with a fixed k.

    Colour and contrast8

    The engine reports success but the page stays violet.

    Cause PALETTE.install() injects its style into the head, before the body-linked stylesheets on an Artifact, so it loses the cascade.

    Fix Link the generated fg3-color.css. A generator is not a guarantee.

    Secondary text fails on a fill.

    Cause #6e6e73 drops to about 3.85:1 on a fill: four grounds need four inks.

    Fix --label-2-on-fill on fills, -strong on tints. Let the ground declare the adjustment; do not refit the ramp.

    Increased contrast made labels identical.

    Cause Refitting every role to 7:1 collapsed --label-2 and --label-3 into one hex.

    Fix Treat it as a fifth ground: a step toward the ink, not a raised target.

    Violet text is hard to read.

    Cause #7c5cff is a fill colour: 3.90:1 as ink. A gradient must be judged at its lightest stop.

    Fix Text uses --accent, the fitted ink.

    A caption fails the audit at 3.3:1.

    Cause --label-3 is the tertiary label, a 3:1 role.

    Fix Captions and any text at 17 px or below use --label-2.

    The audit reports ratios that cannot be right.

    Cause color-mix() computes to oklab(), and a gradient reads as transparent to a naive DOM walk.

    Fix Parse colours through a 1×1 canvas; report unmeasurable separately from passed.

    Semantic colours look washed out.

    Cause Hues are fitted at the accent’s chroma, so a near-grey accent mutes them.

    Fix Emphasise the primary action by fill, not hue; keep red for Stop and errors.

    Corners, layout and CSS10

    Safari and Firefox draw circles.

    Cause corner-shape is dropped where unsupported.

    Fix FG3’s fallback covers every selector that declares it, not a handful of classes.

    A pill looks like a lozenge.

    Cause A capsule was given the continuous k and the 1.53 scale.

    Fix .capsule: corner-shape: round. FG3 snaps a clamped radius for you.

    A list ignores its margin or padding.

    Cause The reset’s ul[class]{margin:0;padding:0} is (0,1,1) and beats a single-class rule.

    Fix Write ul.my-list.

    A hidden element shows.

    Cause [hidden] loses to any display rule.

    Fix fg3.css declares [hidden]{display:none!important}; keep it.

    A comment swallows the next rule.

    Cause A comment that closes early turns prose into a selector.

    Fix The build’s comments gate refuses an unbalanced block comment.

    A variant class changes nothing.

    Cause It sets a variable no rule consumes, or a shared sheet queries a class it never defines.

    Fix node tools/check-vars.mjs --strict.

    A variable read by a child layer is always its initial value.

    Cause @property with inherits: false.

    Fix Register properties that child layers read with inherits: true.

    A toolbar or table overflows at 402.

    Cause A display: flex row without flex-wrap; a nowrap cell (one overflowed a phone by 99 px).

    Fix Wrap rows; put wide tables in .table-scroll.

    A sticky overlay shifts the content under it.

    Cause A sticky element with a height and a negative margin collapses with the next sibling’s margin.

    Fix Make overlays zero-height anchors with hanging layers.

    100cqh resolves to zero.

    Cause A container-type: size flex item whose column parent has only a min-height.

    Fix Give the parent a definite height.

    Keyboard and accessibility7

    Tab lands on something invisible.

    Cause opacity: 0 keeps an element in the tab order.

    Fix Reveal on :focus-visible or :focus-within, or remove it from the order.

    The keyboard ring disappeared.

    Cause A :focus{outline:none} rule also removes the keyboard ring.

    Fix Colour on :focus, ring on :focus-visible.

    Forced colours shows gradient buttons with no edges.

    Cause It removes box-shadow (every hairline) but keeps background-image.

    Fix Outlines at offset −1, background-image: none, system colours only.

    A screen reader announces an icon, not an action.

    Cause The name was put on the symbol.

    Fix The accessible name goes on the button; the glyph stays aria-hidden.

    A glyph points the wrong way in right-to-left text.

    Cause Transforms are not logical properties.

    Fix Direction becomes the number --dir; directional glyphs mirror on the <use>, not the <svg>.

    Glyphs each sit on their own line.

    Cause A reset’s svg{display:block}.

    Fix .sym is inline-block.

    A chart draws nothing, or reverts after a resize.

    Cause A flat series divides by a zero range; a direct CHART call was undone by the next mount or resize.

    Fix The extent pads a flat series; the host remembers the values it was given.

    Publishing and tooling9

    Every colour is empty on the published page.

    Cause The host owns <html>, <head> and <body>; tokens on <body> vanish.

    Fix Tokens on :root; set data-tone during parse (the build does).

    Type is slightly off after publishing.

    Cause A stylesheet names its fonts relative to itself; inlining it broke the URLs.

    Fix Keep stylesheets linked; assert that no woff2 404s.

    An asset fails with a MIME error after a republish.

    Cause A republish replaces the whole file set.

    Fix Pass the whole map from dist/publish-map.json every time.

    Dashes and quotes turn into mojibake.

    Cause The host may drop the charset.

    Fix Displayed non-ASCII as entities; the build’s ascii gate escapes the rest.

    A script breaks at parse time after an edit.

    Cause An editor turned \uXXXX escapes into literal characters; a U+2028 inside a regex ended the line.

    Fix Escape invisible characters after writing; the syntax gate catches it.

    A scripted edit silently changed $$( to $(.

    Cause String.prototype.replace treats $$ in a replacement string as $.

    Fix Always pass a function as the replacement.

    The build refuses a link.

    Cause The linked page is not in tools/pages.json.

    Fix List every page a page links to.

    Headless captures are always dark, or always touch.

    Cause Headless Edge inherits the OS colour scheme, and this Windows box reports ten touch points.

    Fix Capture light with FG3.setTone('light'); do not read fd-touch as a phone.

    A test frame renders dark inside a light page.

    Cause Chrome gives a same-origin iframe its embedder’s used colour scheme.

    Fix Set data-tone on the frame’s <html>.
