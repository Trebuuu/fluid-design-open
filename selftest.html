Self-test

Every claim, measured.

The assertions below run against the real assets, in this browser, every time the page opens. Each reads back what the engine produced — a computed style, a pixel, a path length — not what it says it did. Each one has been seen failing on purpose.

How it is proven.

Every row has been red.

An assertion you have never seen fail passes exactly the same when the product is broken. The headless runner serves a deliberately broken copy of one asset at a time — the file on disk is never touched — and refuses to pass unless the rows that cover it turn red.

node tools/run-selftest.mjs
node tools/run-selftest.mjs --width 402 --dark
node tools/run-selftest.mjs --mutants

Lists come from the source.

The palette roles come from PALETTE.ROLES, the brand files from its presets, the corner rules from the stylesheets themselves, the springs from SPRING.NAMED. A hand-typed list drifts; a derived one cannot miss the thing that was added yesterday.

What this page cannot see.

Safari itself, Firefox, a real phone’s GPU and forced colours are not in this browser. The corner and reduced-motion paths are emulated faithfully, and the audit measures contrast on the rendered pages; where a check cannot run here it says skipped and why.

Type is held to measured values.

Sizes, line heights and tracking are compared with reference values measured at the same width, not with our own tokens — a token that drifts from the reference fails here even if every page still agrees with it.
