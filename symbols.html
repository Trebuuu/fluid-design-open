Symbols

Symbols are type.

76 glyphs on one 24-unit grid. They size with the text, sit on its cap height and take their weight from its role, so a caption’s glyph is drawn heavier than a title’s.

312 Follow Send 6:00

One line at the headline role. Every glyph is 1 em, centred on the cap height, stroked 1.24 units at this size.

Every glyph, one grid.

Rendering modes

One markup. Four looks.

Each glyph is drawn in up to four layers. A class decides how they are inked, and the colours cross into the glyph as inherited custom properties.

Monochrome

Every layer takes the text colour. The default, and the only mode on glass.

<i data-sym="camera">

Hierarchical

The secondary layers fade to 58% and 30% of the ink, so the meaning leads.

data-sym-class="sym-hier"

Palette

Layer two takes the accent, layer three a tertiary grey. Set your own with --sym-layer-2.

data-sym-class="sym-palette"

Semantic

A status tint from the palette roles, only where the glyph carries a state.

data-sym-class="sym-ok"

A fourth symbol mode could be multicolour. This set has no fixed-colour artwork, so the status tint takes that place.

A glyph is 1 em square and drops 0.13 em below the baseline, which centres it on the cap height in both SF and Inter. Its stroke comes from the type role: 2.15 units at caption sizes, 1.24 at display sizes. Change the weight and the glyph follows the text.

Arrows turn. Clocks don’t.

Left to right

dir="ltr"

Right to left

dir="rtl"

15 glyphs have a handedness and mirror under dir="rtl" (in accent above). Clocks, the clockwise arrow, vertical arrows and devices never flip. The flip is on the inner <use>, so a glyph that is also animating keeps its mirror.

Add sym-noflip when a directional glyph means a physical direction, such as a media control that must match hardware.

Content transitions

Change the glyph, not the button.

SYM.replace is a replace transition: the old glyph shrinks away, the new one arrives on the toggle spring, in the same box. Press each one.

Play ↔ Pause

play ↔ pause

Follow ↔ Following

person-add ↔ checkmark

Confirms, then returns

doc → checkmark → doc

Record ↔ Stop

record ↔ pause

Under reduced motion the swap is immediate and the new glyph fades in over 120 ms. Which glyph is showing is information, and it survives.

button.addEventListener('click', () => {
  playing = !playing;
  SYM.replace(button, playing ? 'pause' : 'play');
  button.setAttribute('aria-label', playing ? 'Pause' : 'Play');
});

Name what a glyph means

Beside a label a glyph is decoration and is hidden from assistive technology. Standing alone, it needs a name: data-sym-label gives it role="img" and a title. On an icon-only button, name the button instead.

<i data-sym="shield" data-sym-label="Protected"></i>
<button class="btn btn-icon" aria-label="Search">
  <i data-sym="magnifier"></i>
</button>

Unknown names show themselves

A misspelt name renders a red square and logs a warning, so a missing icon never passes for a spacing bug. shape is an alias of sliders.
