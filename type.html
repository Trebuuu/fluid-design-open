Typography

Fourteen sizes. Two weights.

Product pages are set from fourteen sizes, each with its own leading and tracking, in two weights — 600 for headlines, 400 for everything else. The ramp is written in rem, so a reader’s larger default text scales the whole ramp. Apps use text styles with dynamic type instead.

Orbit

The list comes to you.

Orbit picks the project that is furthest behind, starts up once at a review and clears six to twelve tasks in that single visit. Every run writes its own ledger row, so the daily limits count exactly what the workspace did.

Apps

Dynamic type.

The console and the phone companion use the app text styles at the default size, Large. Dense screens switch to data-density="compact", which is the next size down — the whole ramp moves one step, never a single style.

System face and Inter

The system face where it lives. Inter everywhere else.

The system face’s licence keeps it on its own platforms, so it is never shipped — those devices reach it through -apple-system. Everyone else gets Inter, bundled in assets/: an open licence, a weight axis from 100 to 900 and an optical-size axis that tightens display cuts the way the system face does.

Symbols

A symbol is a letter.

Glyphs are sized in em and centred on the cap height, so they move with the text. The type role sets the stroke: it grows with the size, only more slowly, the way symbol sets draw a different weight at each optical size.
